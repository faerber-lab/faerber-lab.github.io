datasets

Selected datasets and resources from our group.

Selected datasets and resources (curated). For context and publications, see /publications/ and /projects/.

  • SemRepo
    Knowledge Graph · 2025 · Open Science, GitHub, RDF, Knowledge Graph
    RDF KG of ~200k GitHub repos linked to scientific papers (incl. SPARQL endpoint + ontology).
    License: CC BY 4.0
    Links:Zenodo · Homepage
  • HF-NLP10K
    Dataset · 2025 · Hugging Face, Model Metadata, LLMs
    Structured dataset of 10,000+ Hugging Face NLP models with enriched metadata.
    License: CC BY 4.0
    Links:Zenodo
  • Graph Machine Learning Dataset LinkedMDB (LinkedMDB-GML)
    GML Dataset · 2024 · Graph ML, Benchmark, RDF
    Heterogeneous graph ML dataset derived from the LinkedMDB RDF KG (AutoRDF2GML).
    License: CC BY 4.0
    Links:Zenodo
  • Graph Machine Learning Dataset AIFB (AIFB-GML)
    GML Dataset · 2024 · Graph ML, Benchmark, RDF
    Heterogeneous graph ML dataset derived from the AIFB RDF KG (AutoRDF2GML).
    License: CC BY 4.0
    Links:Zenodo
  • Linked Papers With Code (LPWC)
    Knowledge Graph · 2024 · Machine Learning, RDF, Knowledge Graph
    RDF KG for ~400k ML papers incl. tasks, datasets, methods, evaluations, and results.
    License: CC BY 4.0
    Links:Homepage · Zenodo (RDF KG snapshot) · Paper (arXiv) · Code (pipeline)
  • RDF Knowledge Graph SemOpenAlex-SemanticWeb
    Knowledge Graph · 2023 · RDF, Knowledge Graph, SemOpenAlex
    Subset of SemOpenAlex focusing on the Semantic Web community (with embeddings).
    Links:Zenodo
  • Graph Machine Learning Dataset SOA-SW
    GML Dataset · 2023 · Graph ML, Benchmark, SemOpenAlex
    Heterogeneous graph ML benchmark derived from SemOpenAlex-SemanticWeb.
    License: CC0
    Links:Zenodo
  • Graph Machine Learning Dataset LPWC
    GML Dataset · 2023 · Graph ML, Benchmark, LPWC
    Heterogeneous graph ML benchmark derived from LPWC (papers/datasets/tasks/methods + features).
    License: CC BY-SA 4.0
    Links:Zenodo
  • unarXive (open subset)
    Dataset · 2023 · Scholarly Full Text, NLP, Citations
    Structured full-text corpus from arXiv (open subset: permissively licensed papers).
    License: See arXiv licenses
    Links:Homepage · Zenodo (open subset) · Zenodo (full version) · Paper (arXiv) · Code
  • SemOpenAlex
    Knowledge Graph · 2023 · Scholarly Data, RDF, Knowledge Graph
    Massive scholarly RDF knowledge graph (publications, authors, venues, concepts).
    License: CC0
    Links:Homepage · Paper (arXiv) · Embeddings (Zenodo v1)
  • Data for Cyrillic Reference Parsing
    Dataset · 2021 · NLP, Citations, Low-resource
    Synthetic + manually annotated references for citation field extraction in Cyrillic scripts.

  • Microsoft Academic Knowledge Graph (MAKG)
    Knowledge Graph · 2021 · Scholarly Data, RDF, Knowledge Graph
    Massive RDF knowledge graph of scholarly metadata.

  • Data Set Knowledge Graph (DSKG)
    Knowledge Graph · 2021 · Datasets, RDF, Knowledge Graph
